## Сайт-портфолио

В репозитории находится самостоятельная страница [`index.html`](./index.html), которая использует только HTML, CSS и JavaScript. Возможности:

- Адаптивный дизайн для мобильных устройств и компьютеров;
- Светлая и тёмная темы с сохранением выбора;
- Фильтрация проектов по статусу публикации;
- Ссылки на доступные репозитории и архивы;
- Никаких внешних библиотек и сборки.

Чтобы запустить локально, откройте `index.html` в браузере.
