# Nomad Convert — локальный конвертер файлов

Работает **локально на Ubuntu**. Интерфейс открывается в браузере, а обработка происходит на этом же ноутбуке. Файлы **не отправляются в интернет**: сервер слушает только `127.0.0.1`.

## Запуск на Ubuntu

1. Распакуй архив проекта.
2. В открытой папке проекта нажми правой кнопкой → «Открыть в терминале».
3. Запусти:

   ```bash
   chmod +x start.sh
   ./start.sh
   ```

4. Открой **http://127.0.0.1:8765**. При запуске сайт обычно открывается сам.
5. Чтобы остановить сайт, нажми **Ctrl + C** в терминале.

При первом запуске `start.sh` создаёт виртуальное окружение `.venv` и однократно устанавливает Python-библиотеки из `requirements.txt` (для установки нужен интернет). **После этого конвертация работает без интернета.**

Если `python3 -m venv` не работает:

```bash
sudo apt update
sudo apt install python3-venv python3-pip
```

Для обработки видео и аудио нужен FFmpeg:

```bash
sudo apt install ffmpeg
```

Для DOCX, ODT и PPTX → PDF нужен LibreOffice:

```bash
sudo apt install libreoffice-writer libreoffice-impress
```

Если FFmpeg или LibreOffice отсутствуют, интерфейс не предлагает соответствующие форматы.

## Поддерживаемые операции

| Источник | Результат |
|---|---|
| PNG, JPG/JPEG, WEBP, BMP, TIFF, GIF, ICO | PNG, JPG, WEBP, BMP, TIFF, GIF, ICO, PDF (кроме исходного формата) |
| MP4, WEBM, MOV, MKV, AVI, M4V, WMV, FLV | MP4, WEBM, MOV, MKV, AVI, GIF, MP3, WAV |
| MP3, WAV, FLAC, OGG, OPUS, M4A, AAC, WMA | MP3, WAV, FLAC, OGG, OPUS, M4A, AAC |
| PDF | TXT, PNG, JPG |
| DOCX | TXT, PDF (с LibreOffice) |
| TXT | DOCX, PDF |
| ODT, PPTX | PDF (с LibreOffice) |
| CSV, TSV, XLSX, JSON | CSV, TSV, XLSX, JSON |
| Два и более PDF | Объединение в один PDF |
| Любые файлы | Объединение в ZIP |

**Особенности:**
- GIF → статичное изображение берёт первый кадр. Для анимированного GIF из видео выбери «Видео → GIF».
- PDF из нескольких страниц → PNG/JPG выдаёт ZIP с изображениями всех страниц.
- PDF → TXT требует текстовый слой: сканы без OCR не поддерживаются.
- XLSX читается с первого листа; при переводе в CSV/JSON форматирование и формулы не сохраняются. Значения формул берутся из кэша Excel.
- Видео → MP3/WAV извлекает звуковую дорожку (если она есть).
- Максимум 800 МБ **на HTTP-запрос**; для архивов и объединения PDF суммарный размер файлов также ограничен 800 МБ.
- Временные результаты сохраняются в `~/.cache/nomad-convert/jobs` и удаляются при нажатии «Очистить» или после шести часов при очередном использовании приложения. Скачать результат следует до очистки.
- Сервер запускается только вручную и **не остаётся в фоне** после закрытия процесса.
- Обработка не гарантирует сохранение сложных макетов документов и таблиц.

## FAQ

**Как сделать MP4 для WhatsApp из Ubuntu WebM?** Нажми «WEBM → MP4», выбери запись экрана, затем «Конвертировать» и скачай MP4 с кодеком H.264.

**Можно ли использовать без сети?** Да, после первоначальной установки зависимостей.

**Кто видит мои файлы?** Локальный процесс Python на устройстве. Не открывай сервер во внешней сети; по умолчанию он доступен только на `127.0.0.1`.

**Как удалить все временные файлы вручную?** Закрой сервер и выполни:

```bash
rm -rf ~/.cache/nomad-convert/jobs
```

**Как полностью удалить приложение?** Останови сервер, удали папку проекта и при желании папку `~/.cache/nomad-convert`.

## Структура проекта

- `app.py` — локальный HTTP-сервер и API
- `converter.py` — конвертация файлов
- `static/styles.css`, `static/app.js` — адаптивный интерфейс (без внешних CSS/JS)
- `templates/index.html` — веб-страница
- `start.sh` — запуск одной командой

**Не следует открывать `index.html` двойным кликом:** для конвертации нужен локальный Python-сервер.
