# Nomad Convert — локальный сайт-конвертер для Ubuntu

Версия **NPM Edition**. Открывается в браузере, запускается из **Visual Studio Code** двумя командами, не использует облачные сервисы и не отправляет файлы за пределы компьютера.

## Быстрый запуск

Требуется **Node.js 18+** и npm.

1. Распакуй проект и открой папку `NomadConvert_NPM` через **VS Code → File → Open Folder**.
2. Открой терминал VS Code (`Ctrl + \``).
3. Выполни:

```bash
npm install
npm run dev
```

4. Перейди по адресу **http://127.0.0.1:8765**.
5. Остановка сервера: **Ctrl + C** в терминале VS Code.

Важно: команда **`npm run dev` запускает и сам сайт, и локальный сервер конвертации** — отдельного Python, Flask, Vite или запуска второго терминала не требуется.

`npm install` может выполняться без интернета: у проекта **нет внешних npm-зависимостей**. Это не означает, что FFmpeg и LibreOffice устанавливаются через npm; для расширенных форматов нужны системные утилиты (см. ниже).

## Установка системных конвертеров (Ubuntu)

Для полной поддержки форматов:

```bash
sudo apt update
sudo apt install -y ffmpeg imagemagick poppler-utils libreoffice-writer libreoffice-calc libreoffice-impress
```

При отсутствии части программ сайт **всё равно запускается**, но не предлагает операции, которые требуют этих программ. FFmpeg нужен для видео и аудио, ImageMagick/FFmpeg — для изображений, Poppler — для извлечения страниц и текста из PDF, LibreOffice — для DOCX, XLSX и некоторых PDF-преобразований.

**Для WebM → MP4 (WhatsApp)** нужен только FFmpeg, который можно установить отдельно:

```bash
sudo apt install ffmpeg
```

## Возможности

| Тип файлов | Операции |
| --- | --- |
| Видео | WEBM / MOV / MKV / AVI / MP4 → MP4, WEBM, MOV, MKV, AVI, GIF, MP3, WAV |
| Аудио | MP3 / WAV / FLAC / OGG / OPUS / M4A / AAC / WMA → MP3, WAV, FLAC, OGG, OPUS, M4A, AAC |
| Изображения | PNG / JPG / WEBP / BMP / TIFF / GIF / ICO → PNG, JPG, WEBP, BMP, TIFF, GIF, ICO, PDF |
| Документы | PDF → TXT, PNG, JPG; DOCX → TXT/PDF; TXT → DOCX/PDF; ODT/PPTX → PDF |
| Таблицы | CSV / TSV / JSON / XLSX → CSV, TSV, JSON, XLSX |
| Дополнительно | Объединение PDF, создание ZIP, конвертация нескольких файлов подряд, скачивание результатов |

### Особенности

- MP4 кодируется в **H.264 + AAC** с `yuv420p` для совместимости с WhatsApp.
- Для извлечения звука из видео нужна звуковая дорожка.
- Для PDF → TXT нужен **текстовый слой**; OCR сканов не предусмотрен.
- PDF из нескольких страниц → PNG/JPG возвращает ZIP с отдельными страницами.
- При CSV/TSV/JSON/XLSX переводятся данные, а не оформление и формулы Excel.
- Анимированный GIF при переводе в статичное изображение отдаёт первый кадр.
- У ZIP-архивов используется стандартный метод `STORE`: файлы упаковываются без сжатия, но архив работает в обычных архиваторах.
- Сайт слушает **только `127.0.0.1`** и не доступен из интернета/локальной сети по умолчанию.
- Временные файлы сохраняются в `.cache/` и автоматически удаляются спустя **6 часов**. Кнопка «Очистить» сразу удаляет готовые результаты.
- Максимальный размер одного файла и всех файлов в одной операции объединения — **800 МБ**.

## Тесты

```bash

```

Тест использует встроенные средства Node.js, не требует дополнительных npm-модулей и проверяет API, CSV → JSON, JSON → TSV и ZIP.

## Решение проблем

**Порт занят:** запусти `PORT=8877 npm run dev` и перейди на `http://127.0.0.1:8877`.

**Не работает WebM → MP4:** проверь `ffmpeg -version`; если команда не найдена, установи `sudo apt install ffmpeg` и перезапусти сервер.

**Нет DOCX → PDF:** установи `libreoffice-writer`.

**Запуск не работает:** проверь `node -v` (нужна версия не ниже 18) и `npm -v`.

**Удаление:** останови сервер и удали папку проекта. Никаких служб `systemd` он не создаёт.
